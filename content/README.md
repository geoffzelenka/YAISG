# Placeholder content

These files are deliberately fake scaffolding for engine and integration tests.
They are not intended to establish names, balance, or final game content.

`xp_curve.json` is generated by `python content/generate_xp_curve.py`. Level 1
requires zero XP. For each level `L` from 2 through 99, the cumulative table
adds:

```text
floor(100 * 1.12 ** (L - 2))
```

Run the generator and commit its deterministic output whenever the formula is
changed.
