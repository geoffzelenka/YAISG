# YAISG - XP Curve and Tier vision document

# XP
XP (eXperience Points) are earned from completing activity cycles.  The player will begin at level 0 and earn level 1 the first time they do a skills activity and travel along the XP Curve by accumulating XP until they earn enough to cross a new level's threshold up to skill level 100.  At level 100, the player can still accumulate XP, though it won't do anything besides being something to brag about.


# Tiers
Version 1.0 will launch with 5 tiers and represent the player's aptitude.  The exact title's will be the responsibility of the content designer.  The threshold for the 5 tiers will be at 1, 50, 75, 90, and 95.

The tiers will provide bonuses to the skills performed themselves:
 * Gatherers will get a yield increase for lower tiers, 4 tiers below get 50% increase, 3 tiers below get 25% increase, 2 tiers below a 15%, and 1 tier below a 5%.
 * Refiners get a faster cycle time: 2 tiers below 5%, 3 tiers below 10%, 4 tiers below 20%
 * Manufacturer get yield increase and faster cycle time: 2 tiers 5%, 3 tiers 10% and 4 tiers 20%
 * Combat vision owns the combat bonuses
 * Travel gets faster cycle time and lowered material cost
 * exploration would receive a faster cycle time and more keys

# XP Curve vs Time to achieve a new tier
The goal of the XP Curve is to time gate optimal/perfect play to achieving new tiers, thus giving a tight relationship between xp/time of a skill and the where it unlocks on the XP Curve.  So there is a test between a given activities xp per time awards and where it unlocks.  Different classes of skills (gathering, refining, manufacturing, combat, exploring, traveling, etc) will have different baselines for how long its expected it would take to max out.

Level 93 should be roughly the half-way mark in XP and time spent.

Baseline for skilling time would be: if you only performed the first available skill action - it would take 2,880 hours (4 months), while optimal skill progression would take 720 hours, and a fully loaded set of bonuses at v1.0 lauch take about 500 hours.

Gathering skills have no diminishing returns from activities and no real gates to increasing tiers.

Refining skills would start to have dimishing returns from 2 tiers below and 3 tiers below would stop gaining xp.  Tier gates would be refining something from current tier.

Manufacturing skills would have diminishing returns on the tier below, and no skill gain 2 tiers below.  A set of things manufactured would be required to be made in order to achieve the next tier.

Combat - there is already a vision for diminishing returns in the combat vision doc.

Exploration and travel would have no diminishing returns.


# Skills and Tiers
The majority of skill activities will be in tiers 1 and 2.  Gathering, Refining, and Manufacturing should aim for an activity to unlock at every 10 XP levels.

Travelling being a skill allows an additional gate to border realms.  Content designer can add this to inter-realm edges.
