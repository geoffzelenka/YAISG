# Prompt 3.3 — Client skill panels and global action strip

Implemented live Gathering, Refining, and Crafting routes backed by the available-actions endpoint and cached placeholder content. Action cards show requirements, inputs, authoritative drop definitions/rates, effective cycle time, blockers, and start controls.

Added a persistent active-action strip with a single Zustand clock ticking four times per second, cosmetic server-timestamp progress, boundary-aligned polling with ±10% jitter, focus/reconnect refresh, stop controls, transient reward toasts with persistent scrollback, stop-reason reporting, and a welcome-back summary for reward deltas spanning more than five cycles. Polling is single-flight and recovers after request failures. Profile and inventory queries are invalidated after authoritative reward changes and on focus/reconnect so a lost reward response cannot leave displayed state stale.

Added the Profile inventory grid with named stacks and used-stack versus `inventory_slots` capacity. Reward displays resolve content names and include overflow and level-up information. Action errors preserve server messages, and the welcome-back dialog supports Escape-to-close and initial focus. Vitest/Testing Library coverage includes locked/startable actions, recipes and rates, progress math, the offline threshold/modal, the shared clock, boundary scheduling, and failure-resilient single-flight polling.

No game content or §10 non-goals were added.

Known gap deferred to a server-focused change: the inventory API does not expose the character's resolved `inventory_slots` cap. The client therefore displays the placeholder pack's base cap and cannot yet reflect future estate or realm cap bonuses. The server should expose resolved caps on the profile or inventory response before upgrade-derived inventory capacity is introduced.

Review follow-up: API error parsing now preserves structured error codes and messages while safely falling back to HTTP status text or a caller-provided message for empty, malformed, or non-JSON error responses.
